A FIELD GUIDE

Learn the rhythm.

Morse code turns letters and numbers into short signals (dots) and long signals (dashes). It can travel as sound, light, or radio.

01

Hear the shape

A dot is one beat. A dash lasts three beats. Leave a short pause between letters and a longer one between words.

02

Learn by sound

Practice letters as rhythms instead of counting dots. Start with E (dit), T (dah), and SOS (dit dit dit · dah dah dah · dit dit dit).

03

Build a habit

Practice a few minutes each day: listen, copy a short phrase, then decode it. Add letters gradually and keep the pace relaxed.
